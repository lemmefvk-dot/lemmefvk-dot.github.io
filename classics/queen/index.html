StaticOS Free Classics: Flight of the Amazon Queen

John Passfield and Steve Stamatiadis, 1995. Licence and source for the copy on StaticOS’s Free Classics shelf.

Flight of the Amazon Queen was made by John Passfield and Steve Stamatiadis in 1995. They released it as freeware, and it runs here on ScummVM, by The ScummVM Team. StaticOS did not make this game and does not own it, and neither its authors nor the ScummVM Team have anything to do with StaticOS.

The game’s files

FOTAQ_Floppy.zip is the official download from scummvm.org/games, byte for byte, with its readme inside. It is not modified. SHA-256 2e59de85f708cdb32bf85c85b394ac091c05f7647e856b71f5b3ae73fde761e0, which matches what scummvm.org publishes. queen.tbl, which the engine needs beside it, is ScummVM’s own dists/engine-data/queen.tbl, gzipped (here).

The licence beside it, readme.txt, is copied out of the zip so it can be read here. It says: “1) You may distribute this game for free on any medium, provided this Readme and all associated copyright notices and disclaimers are left intact.” The game may not be sold. All game content is © John Passfield and Steven Stamatiadis.

Source code

This engine is ScummVM tag v2026.4.0, commit 7d2709da5136866589f7602f5f5a7b17de03420e, with one patch, built with Emscripten 4.0.10 (emsdk commit d7b4130688bfa348392b921ab04015aa15c4f154): the free build of build-scummvm-more.sh, with only the queen, lure and drascula engines in it.

  • The source both of StaticOS’s further ScummVM builds were made from (20.3 MB), hosted here: the tag without the engines neither build uses. The engine was built from exactly this file.
  • Our patch: it lets the engine run in a sandboxed frame. We modified the engine on 2026-10-31.
  • The exact build script, with every configure flag and how the tarball is made from the tag, and its small helper.
  • The full upstream tree, with every engine: v2026.4.0.tar.gz.
