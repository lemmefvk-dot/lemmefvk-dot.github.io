StaticOS Free Classics: Drascula: The Vampire Strikes Back

Alcachofa Soft, 1996. Licence and source for the copy on StaticOS’s Free Classics shelf.

Drascula: The Vampire Strikes Back was made by Alcachofa Soft S.L. in 1996. Alcachofa Soft released it as freeware, and it runs here on ScummVM, by The ScummVM Team. StaticOS did not make this game and does not own it, and neither Alcachofa Soft nor the ScummVM Team has anything to do with StaticOS. The game’s music is a separate download from scummvm.org (36 MB) that this copy leaves out, so the game says at the start that its CD music is missing.

The game’s files

drascula-1.0.zip is the official download from scummvm.org/games, byte for byte, with its readme inside. It is not modified. SHA-256 b731f6cb5a22ba8b4c3b3362f570b9a10a67b6cb0b395394b19a94b36e4e42de, which matches what scummvm.org publishes. Its manual, drascula.doc, stays in the zip and out of the game’s frame. drascula.dat, which the engine needs, is ScummVM’s own dists/engine-data/drascula.dat, gzipped (here).

The licence beside it, readme.txt, is copied out of the zip so it can be read here. It says: “1) You may distribute "DRASCULA" for free on any medium, provided this Readme and all associated copyright notices and disclaimers are left intact.” The game may not be sold. All game content is © Alcachofa Soft S.L..

Source code

This engine is ScummVM tag v2026.4.0, commit 7d2709da5136866589f7602f5f5a7b17de03420e, with one patch, built with Emscripten 4.0.10 (emsdk commit d7b4130688bfa348392b921ab04015aa15c4f154): the free build of build-scummvm-more.sh, with only the queen, lure and drascula engines in it.

  • The source both of StaticOS’s further ScummVM builds were made from (20.3 MB), hosted here: the tag without the engines neither build uses. The engine was built from exactly this file.
  • Our patch: it lets the engine run in a sandboxed frame. We modified the engine on 2026-10-31.
  • The exact build script, with every configure flag and how the tarball is made from the tag, and its small helper.
  • The full upstream tree, with every engine: v2026.4.0.tar.gz.
