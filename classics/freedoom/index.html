StaticOS Free Classics: Freedoom: Phase 1

The Freedoom project · engine from id Software’s Doom, 2024. Licence and source for the copy on StaticOS’s Free Classics shelf.

Freedoom is free game data for the Doom engine, made by the contributors to the Freedoom project. It contains no id Software art. Freedoom: Phase 1 is its four-episode game. The engine is doomgeneric, a small port of Chocolate Doom, which is built on the Doom source code id Software released under the GNU GPL. You can also play your own DOOM.WAD or DOOM2.WAD with it: it is read in your browser and never uploaded. StaticOS did not make any of this, and none of these projects has anything to do with StaticOS.

The game’s files

freedoom1.wad.gz is freedoom1.wad from the official freedoom-0.13.0.zip (release page), gzipped and otherwise unchanged. The zip’s SHA-256, 3f9b264f3e3ce503b4fb7f6bdcb1f419d93c7b546f4df3e874dd878db9688f59, matches the checksum file the Freedoom project signs and publishes beside it, and the WAD’s own is 7323bcc168c5a45ff10749b339960e98314740a734c30d4b9f3337001f9e703d. The music is silent here: it needs a MIDI synthesiser this build leaves out.

Source code

This engine is doomgeneric at commit e257a09527062bfb986b6e5e0780839b6cbd5b71, unmodified, built with Emscripten 4.0.10 (emsdk commit d7b4130688bfa348392b921ab04015aa15c4f154) and the flags of upstream’s own Makefile.emscripten, less its preloaded WAD and its MIDI player.
