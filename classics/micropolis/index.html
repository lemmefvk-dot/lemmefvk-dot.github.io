StaticOS Free Classics: Micropolis

Electronic Arts · JavaScript port by Graeme McCutcheon, 1989. Licence and source for the copy on StaticOS’s Free Classics shelf.

Micropolis is a city simulator from 1989, released as free software by Electronic Arts for the One Laptop Per Child project. This is micropolisJS, a JavaScript port by Graeme McCutcheon, modified to run inside StaticOS. StaticOS did not make this game.
