Run the downloaded website

  1. Extract the ZIP file.
  2. Open a terminal in the extracted folder and run ./serve.sh on macOS/Linux.
  3. On Windows, run py -m http.server 8000 in that folder instead.
  4. Open http://localhost:8000 in your browser.

StaticOS uses browser modules and service workers, so serve the extracted files over HTTP instead of opening index.html directly.
